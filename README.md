# Задачи на программирование
Данный репозиторий содержит выполненные лабораторные работы, целью которых являлось решение 10 задач из книги Programming Challenges (Steven S. Skiena & Miguel A. Revilla). ПИТПО (проектирование и тестирование программного обеспечения) - название учебного предмета, по которому выполнялись лабораторные работы. Для тестирования выполненных задач использовался файл Program.cs, в который вносились тестовые данные.

Автор: студент группы ПИН-241 Сулимов В. А.

## Counting.cs («Counting»)
Комбинаторная задача на подсчёт количества способов разбиения или представления чисел (часто решается с помощью динамического программирования или генерации последовательностей).

## EditStepsLadders.cs («Edit Steps Ladder»)
Даётся словарь. Нужно найти самую длинную цепочку («лестницу») лексикографически упорядоченных слов, где каждое последующее слово получается из предыдущего одним «шагом редактирования» (вставка, удаление или замена одного символа).

## EncryptionII.cs («Encryption II»)
Задача на криптографию и работу со строками, где необходимо реализовать или взломать опредёленный алгоритм шифрования текста (например, шифр перестановки или подстановки).

## ErdosNum.cs («Erdös Numbers»)
На основе списка соавторов научных статей необходимо построить граф и с помощью алгоритма поиска в ширину (BFS) вычислить «число Эрдёша» для каждого учёного (минимальное расстояние до венгерского математика Пала Эрдёша).

## LcdDisplay.cs («LCD Display»)
Задача на симуляцию и форматирование вывода. Требуется отобразить заданные числа в стиле семисегментного жидкокристаллического (ЖК) дисплея с помощью символов дефиса/минуса (-) и вертикальных черт (|) в указанном масштабе.

## Ones.cs («Ones»)
Дано нечётное число n, не делящееся на 5. Требуется найти количество цифр в самом маленьком числе, состоящем только из единиц (1, 11, 111, ...), которое нацело делится на n (решается с помощью модульной арифметики).

## ServicingStations.cs («Servicing Stations»)
Теория графов. Дана сеть городов. Необходимо найти минимальное количество станций обслуживания, которые нужно построить, чтобы каждый город либо сам имел станцию, либо граничил с городом, где она есть. Задача о минимальном доминирующем множестве; решается методом поиска с возвратом (backtracking).

## ShoemakersProblem.cs («Shoemaker's Problem»)
Жадный алгоритм. У сапожника есть N заказов, каждый требует T_i дней на выполнение, а за каждый день просрочки начисляется штраф S_i. Нужно найти оптимальный порядок выполнения работ, минимизирующий суммарный штраф.

## TheGrandDinner.cs («The Grand Dinner»)
Задача о максимальном потоке в графе или о двудольном паросочетании. Команды из разных регионов ужинают за круглыми столами. Нужно рассадить участников так, чтобы за одним столом сидело не более одного представителя от каждой команды, при соблюдении вместимости столов.

## UnidirectionalTSP.cs («Unidirectional TSP»)
Задача коммивояжёра на сетке. Дана матрица чисел (стоимостей). Нужно найти путь с минимальной стоимостью из крайнего левого столбца в крайний правый, двигаясь только вправо, вправо-вверх или вправо-вниз, и вывести лексикографически наименьший из путей минимальной стоимости (динамическое программирование).
